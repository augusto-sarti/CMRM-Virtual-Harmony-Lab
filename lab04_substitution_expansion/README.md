# Lab 4 — Substitution & Harmonic Expansion

This module introduces three operations needed before the later blues synthesis lab:

1. functional-family substitution inside C major;
2. tonicization of IV through C7 (V7/IV);
3. ii–V expansion: Gm7–C7–Fmaj7.

Tritone substitution is intentionally reserved for Lab 5.

Audio uses exact local MIDI-number WAV files; no runtime pitch transposition is used.
