# CMRM Harmony Lab 05 — Tritone Substitution

Revision v0.9 focuses on tonal continuity and contextual listening.

- The substitution is now embedded in a full I–vi–ii–V–I phrase in C major.
- The alternate phrase changes only V: I–vi–ii–subV–I.
- Chords use fixed four-part voicings rather than independent chord stacks.
- The substituted cadence preserves true voice identities:
  - D3 → D♭3 → C3
  - A3 → A♭3 → G3
  - C4 → C♭4/B3 → B3
  - F4 → F4 → E4
- An upper-voices-only A/B mode makes continuity easy to hear.
- Exact local WAV samples are still used with no runtime transposition.
