# CMRM Harmony Lab 6 — Blues Complexification (rebuilt)

This version replaces the earlier synthetic Level 0–4 blues lab with a source-grounded construction lab based on the instructor-provided material.

## Source material used
- `assets/blues_complexification_class_table.png`: classroom comparison table supplied by the instructor.
- `source/chord_substitutions_in_blues.mscz`: supplied MuseScore teaching file.
- `audio/1.mp3` ... `audio/10.mp3`: supplied full-length construction examples.

## Construction sequence recovered from the MuseScore file
The successive systems explicitly annotate operations including `prep. by min 7`, `tritone sub.`, `back-prop. of 7th`, and `left-del.`. The interactive builder preserves the chord symbols and the ordering of those systems while adding explanatory prose.

The tenth source system displays the same harmony symbols as the ninth; the app therefore retains audio example 10 as source playback without inventing a separate harmonic operation.
