# Lab 7 — Reharmonization

This module keeps an eight-note soprano phrase invariant while changing the harmonic support beneath it.

## Versions
- A: plain functional path — Cmaj7 / Dm7 / G7 / Cmaj7
- B: functional-family substitutions — Am7, F, Bm7b5, Em7
- C: reharmonized path using C7 to tonicize IV and Fm6 as modal mixture before G7

## v0.14 revision
The audio modes are now intentionally different: melody + harmony includes the fixed soprano as a separate line, harmony only excludes it, and A/B compares baseline A with B or C after a clear pause.

Section 5 now uses five continuous voices. The version-C realization is: 
- Bass: E3–E3–E3–D3–D3–D3–C3–C3
- Inner 1: G3–G3–F3–F3–F3–F3–E3–E3
- Inner 2: B3–B♭3–A3–A♭3–G3–G3–G3–G3
- Inner 3: C4–C4–C4–C4–B3–B3–B3–B3
- Fixed soprano: E4–G4–A4–F4–F4–D4–E4–C4

The chord symbols are unchanged, but inversions are deliberately allowed to preserve smooth melodic continuity.
