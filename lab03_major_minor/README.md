# Lab 3 — Major vs Minor II–V–I

Default audible comparison: Dm7–G7–Cmaj7 versus Dm7♭5–G7–Cm.

An optional control adds characteristic C-harmonic-minor colour tones, yielding G7(♭9) and Cm(maj7). This deliberately separates the functional cadence from its stronger colour extensions. All pitches use exact local MIDI-numbered WAV files; no runtime transposition is used.
